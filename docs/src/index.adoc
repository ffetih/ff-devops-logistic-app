The {project-name} is a multi-tenant logistics platform, rebuilt sprint by sprint so that every change reaches a local Kubernetes cluster through Git, CI and Argo CD.
It is a practice project inspired by integrated logistics providers, and it follows public logistics standards (GS1, ISO 6346, UN/CEFACT e-CMR, OpenTripModel, EN 16258).

Pick the guide that matches what you need:

| link:identity/identity-guide.html[Identity Service Guide]

More guides come with the parts they describe (analytics, integration, console); the plan is in `docs/backlog.md`.

Version: {project-version}

== How these documents are maintained

* Every guide lives under `docs/src`, together with the shared attributes, the glossary and the roles matrix.
* A change that alters behaviour updates the matching guide in the same commit. A problem met on the cluster gets an entry in the Operations Guide with the item that fixes it.
* CI builds the site on every push and fails on any warning. Locally: `./docs/build-docs.sh` in WSL. See link:platform/platform-guide.html#docs[Working on this documentation].
